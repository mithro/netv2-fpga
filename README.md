# NeTV2 bring-up notes

Working notes for getting the NeTV2 (Alphamax / Kosagi NeTV2 MVP, Artix-7
XC7A35T) board attached to `rpi3-netv2` to lock onto a 1080p60 HDMI signal
generated by the RPi Zero W `rpiz-3`, and verifying the NeTV2 HDMI output
through a USB video capture card attached to `rpi3-netv2`.

- `LOG.md` — chronological work log (every change / test / result).
- `RESOURCES.md` — links to documentation and resources used.
- `scripts/` — helper scripts used during bring-up.

## Hardware (as of 2026-09-05)

| Role | Host | Notes |
|---|---|---|
| HDMI source | `rpiz-3` (RPi Zero W Rev 1.1, Raspbian 13 trixie, kernel 6.18) | PoE+USB ethernet dongle on `gsm7252ps-s1` port 1/0/26 (VLAN 90). HDMI out -> NeTV2 HDMI in. |
| NeTV2 host | `rpi3-netv2` (RPi 3B+, Raspbian 9 stretch, kernel 4.14) | login `pi`. NeTV2 JTAG via GPIO (openocd bcm2835gpio). USB capture card (`345f:2109`, `/dev/video0`) on NeTV2 HDMI out. |
| Switch | `gsm7252ps-s1` | "Top of Xmas Tree Rack in Back Shed". |
